# DANH MỤC CÁC TỪ VIẾT TẮT

<!-- Nhóm trưởng gộp từ report/contrib/*.md; giữ thứ tự ABC. -->

| Từ viết tắt | Viết đầy đủ |
|---|---|
| ACL | Access Control List – Danh sách kiểm soát truy cập |
| AM | ApplicationMaster – Tiến trình điều phối một ứng dụng trên YARN |
| ANOVA | Analysis of Variance – Phân tích phương sai |
| API | Application Programming Interface – Giao diện lập trình ứng dụng |
| AQE | Adaptive Query Execution – Thực thi truy vấn thích ứng (Spark) |
| AUC | Area Under the (ROC) Curve – Diện tích dưới đường ROC |
| BOM | Byte Order Mark – Ký tự đánh dấu thứ tự byte ở đầu tệp |
| CF | Column Family – Họ cột (HBase) |
| CI/CD | Continuous Integration / Continuous Delivery – Tích hợp và phát hành liên tục |
| CSDL | Cơ sở dữ liệu |
| CSV | Comma-Separated Values – Dữ liệu phân tách bằng dấu phẩy |
| DAG | Directed Acyclic Graph – Đồ thị có hướng không chu trình |
| DBI | Database Interface – Gói giao tiếp cơ sở dữ liệu của R |
| EC | Erasure Coding – Mã hóa xóa (lưu dữ liệu kèm khối chẵn lẻ thay cho nhân bản) |
| FPR | False Positive Rate – Tỷ lệ dương tính giả |
| HA | High Availability – Tính sẵn sàng cao |
| HDFS | Hadoop Distributed File System – Hệ thống tệp phân tán Hadoop |
| HFile | Định dạng tệp lưu dữ liệu của HBase trên HDFS |
| HTTP | HyperText Transfer Protocol – Giao thức truyền siêu văn bản |
| ISO 8601 | Chuẩn quốc tế biểu diễn ngày giờ |
| JSON / JSONL | JavaScript Object Notation / JSON Lines (mỗi dòng một đối tượng JSON) |
| JVM | Java Virtual Machine – Máy ảo Java |
| KPI | Key Performance Indicator – Chỉ số đo lường hiệu quả chính |
| MR | MapReduce |
| QJM | Quorum Journal Manager |
| RDD | Resilient Distributed Dataset – Tập dữ liệu phân tán có khả năng phục hồi |
| RFM | Recency – Frequency – Monetary (độ gần, tần suất, giá trị mua) |
| RMSE | Root Mean Squared Error – Căn bậc hai sai số bình phương trung bình |
| ROC | Receiver Operating Characteristic – Đường đặc trưng hoạt động của bộ phân loại |
| SPOF | Single Point of Failure – Điểm hỏng duy nhất |
| SQL | Structured Query Language – Ngôn ngữ truy vấn có cấu trúc |
| TB | Trung bình |
| TMĐT | Thương mại điện tử |
| TSV | Tab-Separated Values – Dữ liệu phân tách bằng tab |
| TTL | Time To Live – Thời gian sống của dữ liệu |
| UDF | User-Defined Function – Hàm do người dùng định nghĩa |
| WAL | Write-Ahead Log – Nhật ký ghi trước |
| YARN | Yet Another Resource Negotiator – Bộ quản lý tài nguyên của Hadoop |
| ZKFC | ZooKeeper Failover Controller |
